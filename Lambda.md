\- **Serverless** compute service that allows us to run code without provisioning or managing servers.

\- We upload our application code, configure triggers/events, and AWS automatically handles infrastructure management, scaling, runtime execution, availability, and maintenance.





**# Lambda helps reduce:**

\- Infrastructure overhead

\- Operational complexity

\- Idle server costs



**# Working :**

\- Lambda follows an *event-driven architecture*.

***Flow:*** <i>Event Trigger → Lambda Executes Code → Returns Response</i>



**When an event occurs:**

* AWS creates/reuses execution environment
* Runs the code/function
* Scales automatically if multiple requests come
* Stops after execution completes



**# Key Benefits**

1. Serverless architecture
2. Automatic scaling
3. Pay-per-use pricing
4. Reduced operational management
5. Easy integration with AWS services
6. High availability managed by AWS
