| State      | Description                      | Command                      |

| ---------- | -------------------------------- | ---------------------------- |

| Created    | Container exists but not started | `docker create`              |

| Running    | Application executing            | `docker start`, `docker run` |

| Paused     | Processes frozen                 | `docker pause`               |

| Exited     | Application stopped              | `docker stop`                |

| Restarting | Restart in progress              | `docker restart`             |

| Dead       | Failed to start or clean up      | Automatic/error state        |

| Removed    | Container deleted                | `docker rm`                  |
