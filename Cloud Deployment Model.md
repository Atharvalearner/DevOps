***1. Public Cloud:*** 

* cloud environment where the infrastructure (servers, storage, networking, etc.) is owned and managed by a third-party cloud provider and shared among multiple customers over the internet. eg. AWS, Azure, GCP
* The physical infrastructure is shared, but each customer's data and resources are logically isolated.





***2. Private Cloud:*** 

* A Private Cloud is a cloud environment dedicated to a single organization. The infrastructure is used only by that organization and is not shared with other customers.
* Only that organization uses the infrastructure.
* eg. Openstack, Azure Stack, VMware





***3. Hybrid Cloud:*** 

* A combination of public and private clouds. 

&#x20;         **Private Cloud (Sensitive Customer Data)**

&#x20;               **│**

&#x20;         **Secure Connection**

&#x20;               **│**

&#x20;         **Public Cloud (Web Applications, Backup)**

* Example: 

A bank stores customer records in its private cloud but uses AWS for backup, disaster recovery, or hosting its public website.
