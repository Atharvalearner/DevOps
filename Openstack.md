***# OpenStack:***

* It is an open-source cloud computing platform 
* used to build and manage private and public cloud infrastructure. 
* It allows organizations to create and manage virtual machines, storage, networking, and other cloud resources, similar to how AWS, Azure, or Google Cloud provide cloud services.
* Its major components include Nova for compute, Neutron for networking, Cinder for block storage, Swift for object storage, Glance for image management, Keystone for authentication, and Horizon for the web dashboard



**Simple Definition:**

OpenStack is software that helps you create your own cloud. Instead of renting servers from AWS or Azure, a company can install OpenStack on its own physical servers and provide cloud services internally.
