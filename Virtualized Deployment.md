* Allows you to **run multiple Virtual Machines (VMs)** on a **single physical server’s.**



* The process of using software (a hypervisor) to create isolated, simulated environments (virtual machines) on physical hardware (single or multiple hardware).



* **Allows applications** to be **isolated** between **VMs.**



* Provides a **level of security** information of one application cannot be accessed by another application.



* Better resources utilization and allows **better scalability** because :

&#x09;▪ an application can be added or updated easily

&#x09;▪ reduces hardware costs



* **Allows multiple servers run on single host machine.**



Advantages :

1. Lower Cost
2. Easy disaster recovery
3. Resource Optimization
4. Rapid Deployment
5. Isolation \& Security



Deployment Models :

1. On-Premise
2. Cloud Based
