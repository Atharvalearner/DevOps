* a **lightweight** **software deployment** method 
* **packages an application’s code, libraries, and dependencies into a single executable unit, or "container**," ensuring consistent operation across different computing environments
* Containers **share the host OS kernel**, making them faster, more portable, and more resource-efficient than (VMs).
* **container has its own filesystem, CPU, memory, process space, and more.**
* Less secure than VM but faster, native or best performance, process-level isolation, **Immutable,** created in seconds.
* To run containers we use Docker/docker engine/container runtime or kubernetes.
