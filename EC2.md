***Elastic Compute Cloud (Amazon EC2) :***

* A web service **providing secure, resizable, on-demand virtual servers** (instances) in the cloud.



* It provides scalable virtual servers (instances) in the cloud, allowing users to run applications without purchasing physical hardware.



* EC2 **supports variety of operating systems**: Linux: Amazon Linux, Ubuntu, Red Hat, SUSE, Fedora, Debian, CentOS, Gentoo Linux, Oracle, FreeBSD, Windows: Windows Server, Windows



* Every instance comprised / contains of :

&#x09;1. Amazon Machine Image (AMI)

&#x09;2. Instance type

&#x09;3. Network Interface

&#x09;4. Storage





***# Why do we use EC2?***

* Host websites
* Run applications
* Deploy APIs
* Host databases
* Run Docker containers
* Development and testing
