***# SDLC (Software Development Life Cycle):***

A structured framework that defines the complete lifecycle of software development, from gathering business requirements to deployment and maintenance, ensuring the software is delivered with high quality, within budget, and on time.



**| ------------ | ------------------ |**

**| Phases       | Deliverable        |**

**| ------------ | ------------------ |**

| Requirements | SRS                |

| Planning     | Project Plan       |

| Design       | HLD \& LLD          |

| Development  | Source Code        |

| Testing      | Test Reports       |

| Deployment   | Production Release |

| Maintenance  | Updates \& Fixes    |

| ------------ | ------------------ |



***# Types of SDLC Models: (For more detail Check Notes)***

1. Waterfall
2. Agile
3. Spiral
4. V-Model
5. Incremental
