\- Technology that **encapsulates an application and its dependencies** in a **way** that **it can run independently** of the **underlying operating system or hardware**.



\- This enables the application to operate in an isolated environment, separate from the host system, without the need for 

direct installation



Types of Application Virtualization

1\. Remote Application Virtualization :

&#x09;▪ application hosted on a remote server and accessed by the user through a client device.

&#x09;▪ Examples: Microsoft RemoteApp, Citrix XenApp



2\. Streaming Application Virtualization :

&#x09;▪ application delivered to user's device on-demand. Only the necessary components are downloaded and executed.

&#x09;▪ Example: VMware ThinApp.



3\. Encapsulation-Based Virtualization:

&#x09;▪ application packaged into a portable format and runs directly on the user’s device.

&#x09;▪ Example: App-V by Microsoft.
