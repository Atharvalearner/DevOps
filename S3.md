Amazon S3, or Simple Storage Service, is AWS's highly scalable object storage service. It stores data as objects inside buckets and is commonly used for files, backups, logs, media, static website content, and application artifacts. S3 provides features such as different storage classes, versioning, lifecycle management, encryption, access control using IAM and bucket policies, and event notifications. It is designed for very high durability and can scale without manually provisioning storage capacity.





***# Simple Storage Service*** *:*

* **highly scalable, high-speed object storage service**
* offered by Amazon Web Services (AWS).
* used for storing and retrieving any amount of data from anywhere on the web.



***# What can be stored?***

Images, Videos, PDFs, Backups, Logs, Static websites, Application assets



***# Core Concepts :***

1. **Buckets** : Each bucket must have a globally unique name.

&#x09;     A container/folder that stores objects(files) in S3.

&#x09;     It is the top-level storage unit in Amazon Web Services S3.



2\. **Objects** : The actual file/data stored inside a bucket.

&#x09;     Files (data) and their descriptive metadata are stored as "objects".

&#x09;     Each object is identified by a unique key (string).

&#x09;     eg. Examples: image.jpg, video.mp4, backup.zip



3\. **Scalability \& Durability** : Automatically replicates data across infrastructure internally.





**# Real analogy :**

Folder 		   -> Bucket

File inside folder -> Object





**# Use Cases**

1. **Static Website Hosting**

2\. **Data Lakes:** Central repository for large-scale analytics and machine learning.

3\. **Backup \& Recovery**: Storing secure, durable backups for disaster recovery.

4\. **Media Storage**: Serving high-volume content for applications like Netflix

5\. **Automatically handling storage scaling**

6\. Replicating data internally
