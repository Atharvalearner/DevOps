**Simple Storage Service** :

* **highly scalable, high-speed object storage service** 
* offered by Amazon Web Services (AWS).
* used for storing and retrieving any amount of data from anywhere on the web. 





*Core Concepts :*

1. **Buckets** : fundamental containers for data. Each bucket must have a globally unique name.

2\. **Objects** : Files (data) and their descriptive metadata are stored as "objects". Each object is identified by a unique key (string).

3\. **Scalability \& Durability**





**Use Cases**

1. **Static Website Hosting**

2\. **Data Lakes:** Central repository for large-scale analytics and machine learning.

3\. **Backup \& Recovery**: Storing secure, durable backups for disaster recovery.

4\. **Media Storage**: Serving high-volume content for applications like Netflix
